Theme
- Dark mode is the default.
- The footer contains a Dark/Light mode toggle.
- The selected theme is stored in localStorage under: jerry-rigs-theme
- Dark mode uses assets/jerry-rigs-logo-dark.png
- Light mode uses assets/jerry-rigs-logo-light.png

Appointments
- Customers can select multiple services.
- At least one service is required.
- Appointment submissions are requests, not guaranteed reservations.
- Requests are reviewed by priority and may be accepted, moved to a later date, or declined.
- The form still needs to be connected to a real email, form, or booking backend before launch.
